Two bands of unicorns have gone to war. Fight it out on the battlefield against a computer opponent, or against a friend (or enemy) face to face, turn by turn.</br></br>Controls:
| Input | Action |
| --- | --- |
| WASD / arrow keys | Movement, position platforms, weapon angle / power |
| Q+E / K+L | Camera left / right (while building or aiming) |
| Z / B | Fire weapon / place platform |
| C / M | Cancel selection |
| X / N | Change weapon / platform type |
| R / J | Rotate platforms |
</br></br>Horns will explode on hitting a platform, destroying it. Drills will destroy any wood platforms they hit, but are destroyed by metal platforms. Beams destroy metal platforms, but are stopped by wood.
